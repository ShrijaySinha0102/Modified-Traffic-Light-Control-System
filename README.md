•	Designed a traffic light control system using Verilog.
•	This implementation includes the traffic light control using time delay in which the Finite State Machine (FSM) is used.
•	The core implementation includes when any emergency vehicle comes near any direction then the traffic light turns green immediately until it crosses the signal.
•	It is very important that the emergency vehicle should get a clear way to pass the signal (other vehicles should not block the way of the emergency vehicle due to huge traffics) so traffic light must turn green.
